# DermLens

Dermoscopic image retrieval research prototype using HAM10000, pretrained ResNet50 embeddings, FAISS similarity search, metadata scoring, and similarity-gated rarity ranking. Includes a FastAPI backend and React/Vite frontend.

## Structure

- `frontend/web/`: React interface for overview, image analysis, metrics, and methodology.
- `backend/`: FastAPI server, evaluation utilities, and smoke-test scripts.
- `src/`: dataset auditing, lesion-grouped splits, embeddings, retrieval, ranking experiments, and statistical analysis.

## Local setup

Use Python 3.11 and Node.js with npm. From the project root in PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Obtain HAM10000 separately and place its metadata and image directories under `data/`:

```text
data/HAM10000_metadata.csv
data/HAM10000_images_part_1/
data/HAM10000_images_part_2/
```

Generate local reference artifacts:

```powershell
.\.venv\Scripts\python.exe src/create_splits.py
.\.venv\Scripts\python.exe src/embeddings.py
.\.venv\Scripts\python.exe src/retrieval.py
```

The backend needs `results/train_embeddings.npy`, `results/train_embedding_metadata.csv`, and `faiss_index/ham10000_resnet.index`. Its metrics dashboard also uses evaluation CSV files generated by research scripts. Some historical scripts contain machine-specific paths; review those paths before running them on a different machine.

Start the backend from the project root:

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000
```

In another terminal:

```powershell
cd frontend/web
npm ci
npm run dev -- --host 127.0.0.1
```

Frontend: http://127.0.0.1:5173/  
API documentation: http://127.0.0.1:8000/docs

## Research status

Results are retrieval scores, not calibrated diagnostic probabilities. The current encoder uses pretrained ImageNet weights. Evaluation audit utilities provide corrected NDCG calculations, but historical evaluation scripts and dashboard outputs may still use legacy metrics. The project is a research prototype and has not been clinically validated.

HAM10000 data, embeddings, FAISS indexes, uploaded images, generated reports, and installed dependencies are excluded from this repository. Dataset and dependency rights remain with their respective owners.
