# Security and safety

Please do not report patient-identifying information, private datasets, API keys, or uploaded clinical images in an issue.

DermLens is an experimental decision-support prototype. Its retrieval results are not a diagnosis and must not be used as a substitute for a qualified clinician.

For a suspected security issue, contact the repository owner privately before opening a public issue. Include a short description, affected component, reproduction steps using synthetic or public data, and the potential impact.

Keep local secrets in environment files that are excluded by `.gitignore`. Dataset files, generated indexes, uploads, and evaluation outputs should remain local.
